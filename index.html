HUGO Courrier

HUGO Courrier est une application personnelle de classement des e-mails Gmail.

Le traitement est réalisé localement sur un Raspberry Pi à l'aide d'Ollama.

L'application utilise les autorisations Gmail pour consulter et organiser les messages du propriétaire du compte.

Aucune donnée Gmail n'est publiée sur ce site.
